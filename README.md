# BiBiChik Booking System

Standalone Next.js, Node.js and Supabase reservation application. Customer routes: /en/reserve, /zh/reserve, /ko/reserve, /ja/reserve, /ms/reserve. Staff: /staff.

Use Node.js 22.13 or later. Run `npm install`, `npm run dev`. Checks: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`. See STANDALONE.md for database and temporary deployment setup. Copy .env.example to .env.local and fill values locally only. No database setup or deployment has been performed.
